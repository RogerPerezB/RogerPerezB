### 🚀 Featured Repositories

#### 1. [Multi-Agent Trajectory Optimization using D-Wave](https://github.com/RogerPerezB/Multi-Agent-Trajectory-Optimization)
*Honours Capstone Research Project &middot; Carleton University*
- Real quantum solution utilizing **D-Wave quantum annealing hardware** and the **Ocean SDK** to solve multi-agent collision-free path planning.
- Formulated routing constraints and obstacle avoidance under a Quadratic Unconstrained Binary Optimization (**QUBO**) model.
- Benchmarked on real D-Wave QPU hardware with custom penalty functions for safety boundaries and arrival synchrony.

*Asynchronous Backend Service &middot; Python & FastAPI*

- Features a clean **Layered Architecture** (Controllers, Services, Schemas, Core) with async connection pooling and hot in-memory caching.
- Self-terminating polling window with deterministic fallback state machine and containerized deployment with Docker.
